# Formato de archivo para importar preguntas

Este archivo muestra el formato correcto para importar preguntas al juego "100 JAS dicen".

## Reglas de formato:

1. Usa `#` para indicar una pregunta
2. Usa `-` o `*` para las respuestas
3. El formato de respuesta puede ser:
   - `Texto de respuesta | puntos` (con puntos específicos)
   - `Texto de respuesta` (se asignarán puntos automáticamente: 40, 30, 20, etc.)
